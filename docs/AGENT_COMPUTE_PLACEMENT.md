# Agent 计算任务调度诊断

在 Agent 运维中选择会话，打开“计算任务”，展开任务详情后选择“任务调度诊断”。
离线或只读会话仍可进入诊断。页面固定绑定该任务和打开时的身份、会话选择，
支持中文、英文及 320 px 窄屏布局。共享 Flutter 代码供 Web / App / Mobile 使用；
原生打包及真实设备联调验收另行进行。

“刷新”读取当前第一页，“下一页设备”只读取下一页，最多显示 20 个设备；每次替换
当前页；观察时间使用本地可读时间，超出平台日期范围时显示提示。页面不累计列表、不自动轮询、不重复提交任务，也不改变任务提交的幂等键。
设备顺序和游标由 Hub 返回，客户端按 Unicode 码点顺序核验。诊断端点不可用
（404 / 405 / 501）时明确显示旧版 Hub 尚不支持，其他任务功能保留。

诊断只呈现任务原始目标集合、当前实例计算授权及项目绑定的交集，不显示隐藏设备
或隐藏数量。可展示离线、生命周期未就绪、忙碌、不可调度、项目不可用、目标授权或
目标不匹配、工作区快照不支持、CPU / 内存不足、操作系统 / 架构 / 运行时不匹配、
GPU 不可用 / 容量不足、设备清单缺失等原因。没有可见绑定不代表没有隐藏容量。
任务不再排队时，仅展示最新状态，不显示旧设备观察。

这些是实时、尽力而为的观察结果。符合条件不代表已预留容量、已获得队列位置或
保证可以执行；执行服务仍按自己的策略裁定。设备原因来自公共投影，不展开
私有 Fabric 数据、路径或凭据。

接口为 `GET /api/v1/agent/tasks/{task_id}/placement?after=DEVICE_ID&limit=20`。
响应仅允许 `{data: {task_id, state, evaluated_at, devices, next_cursor}}`；每行仅
允许 `{device_id, instance_id, eligible, reasons}`。客户端验证请求任务绑定、精确
字段、有限非负时间戳、固定状态 / 原因、布尔 eligibility、唯一升序设备和前进游标；
未知字段、重复 JSON 键、错类型、非法 UTF-8 / 标识符或超出 64 KiB 的响应一律拒绝。

诊断身份固定绑定进入 Agent 页面时的登录状态；打开弹窗前已经换号或退出，也不会发送旧身份请求。身份或源会话选择变化使弹窗失效并清空当前页。每个请求在开始和结束检查身份、
源会话及弹窗生命周期；迟到响应不能恢复旧页。401 / 403 会清空设备与游标并显示
权限错误。诊断请求不会触发共享 transport 的全局登出回调，避免旧请求的 401
更改新身份状态。已经关闭弹窗的读取即使返回，也不再更新界面。
